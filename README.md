# 🐶 Forks Meme — $MEME

Every fork needs a good boy.

Forks Meme is a cute-dog meme coin. Simple as that: cats sell, dogs sell,
and a happy dog with a fork brings luck to everyone who holds it.

## The coin

- **Name:** Forks Meme
- **Ticker:** $MEME
- **Chain:** Solana
- **Launch:** [forks.wiki](https://forks.wiki) — one coin per repository,
  launched on this repo via pump.fun

## How it works

This repository is the home of the $MEME coin. Its creator fees are split
on-chain, for good, between the people behind the code:

- **50%** to the launcher
- **30%** to the repository
- **20%** to forks

The split is locked at launch and can never be changed.
